# Awka–Onitsha Commute Analysis (Power BI)

## 📊 Project Overview
This project delivers a comprehensive **data-driven analysis of commute times between Awka and Onitsha**, two major cities in Anambra State, Nigeria. Using **Power BI dashboards**, raw datasets, and structured documentation, the project uncovers insights into traffic patterns, travel durations, and factors influencing daily commutes.

The goal is to empower policymakers, transport authorities, and commuters with actionable intelligence that can improve **urban mobility, reduce travel stress, and guide infrastructure planning**.

---

## 🚀 Key Features
- **Raw & Cleaned Datasets**: Includes Excel files with original commute data and cleaned versions for analysis.
- **Data Cleaning Documentation**: Step-by-step PDF outlining the transformation process for transparency and reproducibility.
- **Business Questions**: A structured framework guiding the analysis toward practical, real-world problems.
- **Interactive Power BI Dashboard**: Visualizes commute times, peak hours, and comparative trends.
- **Interpretation Report**: A detailed PDF explaining findings, implications, and recommendations.

---

- `7_Commute Time Analysis Interpretation.pdf` → Analytical insights

## 🔍 Insights & Impact
- Identifies **peak travel hours** and their impact on commute duration.
- Highlights **variability in travel times** across different days.
- Provides **recommendations for commuters** (best travel times) and **policy suggestions** (traffic management strategies).
- Demonstrates how **data visualization** can simplify complex urban mobility challenges.
